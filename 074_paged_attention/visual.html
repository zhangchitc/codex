block_pool.py
class BlockHashToBlockMap:
    def __init__(self):
        self._cache: dict[
            BlockHash, KVCacheBlock
        ] = {}

    def get_one_block(
        self, key: BlockHash
    ) -> KVCacheBlock | None:
        return self._cache.get(key)  # O(1)
block table：逻辑块顺序 → 物理块（每个请求对应物理块列表）
