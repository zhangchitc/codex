多头潜在注意力 Multi-Head Latent Attention

多头注意力的问题：KV Cache显存占用太大

MHA 每个头都存自己的 K、V，显存开销太大
推理时缓存
Multi-Head Attention
(MHA)
每个 Q 头都有独立的 K、V
KV 头数 8 · 满额
Multi-Query Attention
(MQA)
所有 Q 头共享同一套 K、V
KV 头数 1 · 只剩 1/8
Grouped-Query Attention
(GQA)
Q 头分组，同组共享一套 K、V
KV 头数 4 · 减半
单token占用KV Cache = 2× L× hkv× dh
以 DeepSeek-V2 为例：注意力头数 hkv = 128，每个头 dh = 128 维，单token占用 L × 32,768 个元素

低秩联合压缩：Low-Rank Key-Value Joint Compression

Key 和 Value 共享潜向量，各头上投影不同
推理时缓存
Multi-Head Attention
(MHA)
每个 Q 头都缓存独立的 K、V
缓存 8 套 K、V
Multi-Head Latent Attention
(MLA)
只缓存一份压缩潜向量，每头 K、V 由它投影出来
缓存 1 份潜向量
单token占用KV Cache = L× dc
潜向量 dc = 512 维，单token占用 L × 512 个元素，是 MHA 的 1/64
